## Before you update

- The `tlh` command now refuses Pi's `--agent-dir` flag, so Pi can't be pointed away from your isolated TLH profile.
- Pi's exit hint now prints a `pi --agent-dir ...` resume command; resume with `tlh --session <id>` instead.

## Updated runtime

- TLH now runs on Pi 1.7.0.

## New

- `/skill:bb` lets you inspect bb (tlh gui) threads, projects, and environments through the bb CLI.
- Set `TLH_PROGRAM_RESUME=1` to let terminals such as Rex and Herdr.app resume plain interactive `tlh` sessions. It's off by default.

## Fixes

- Rex session-start context now shows up in Rex panes as intended.
- A bare `pi` launched from a TLH pane can no longer be restored by terminal program-resume.
