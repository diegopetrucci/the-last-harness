## Before you update

- The only way to skip the launch update check is now `PI_OFFLINE=1`; the `tlh.updateCheck.enabled`, `TLH_SKIP_UPDATE_CHECK`, and `PI_SKIP_VERSION_CHECK` opt-outs are gone.
- `.claude/skills` discovery is always on, and `tlh.claudeSkills.disabled` is now ignored.
- Install, update, and `tlh doctor --repair` now always reset `compaction.reserveTokens` to the packaged value, overwriting yours. For per-model reserves, use `compaction.modelOverrides`.
- `/skill:herdr` is now `/skill:herdr-tui`, so update any habits or prompts that call it by the old name.

## Updated runtime

- TLH now runs on Pi 1.5.2.

## New

- `/skill:herdr-gui-app` helps with the Herdr desktop app and its terminals.

## Fixes

- Claude Pro/Max sign-in requests keep billing correctly in longer conversations.
- Removed a startup tip for a mode that no longer exists.
