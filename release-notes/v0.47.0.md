## Before you update: Node.js 22 is no longer supported

- TLH now needs Node.js 24.22.1 or newer on the 24.x line, or Node.js 26.12.1 or newer. Upgrade Node.js first, then rerun the installer.

## Updated runtime

- TLH now runs on Pi 1.4.0.

## Simpler, sturdier subagents

- Subagent calls now wait for their result by default; ask for background work when you want it.
- Each subagent has its own time budget, and pausing it no longer uses that time up.
- Background results arrive once, right away, and are no longer lost when several tlh sessions are open.
- Interrupting, steering, resuming, or checking a subagent only touches runs from your own session.
- Stopping a subagent now reliably stops everything it started.
- You can run up to 8 subagents in parallel.

## Try ticket-free Architect mode

- Run `/experimental enable no-developer` to let the Architect plan and implement directly, without tickets or a developer subagent.

## Fixes

- `/annotate-last-message` no longer cuts off the bottom of long messages.
- Xcode no longer asks "Allow agent to access Xcode?" again after its MCP bridge has been idle.
- The footer's MCP status line is dimmed like the rest of the footer.
- npm no longer warns about blocked install scripts during install.
