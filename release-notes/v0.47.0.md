## Before you update

- Node.js 22 is no longer supported. You'll need Node.js 24 (24.22.1 or newer) or Node.js 26.12.1 or newer; upgrade, then rerun the installer.
- Background subagent runs started before this update can't be resumed — start them again.
- Project-local `.tlh/defaults.json` model and effort defaults are no longer read. Move them to subagent or primary-agent overrides (see `docs/models.md`).
- `maxSubagentDepth: 0` no longer turns off subagents; the setting is now ignored.

## Updated runtime

- TLH now runs on Pi 1.5.0.

## Subagents in the background

- Subagents now run in the background by default, so you can keep working; you get one notification per run when it finishes.
- Each subagent has its own time budget, and pausing it doesn't use the budget up.
- Resuming the same subagent twice can no longer start two copies on one session.

## New

- The merge-risk skill is bundled, so you can score how risky a PR is to merge.
- TLH registers itself in Herdr.app (opt out with `tlh.herdrApp.enabled: false`).
- In a Rex terminal, your primary agent now gets Rex's session context.
- `/annotate-last-message N` annotates an earlier reply, and the window has per-line note buttons.
- `/effort` Ctrl+S now saves the effort for the current primary agent only.
- An opt-in ticket-free Architect mode.

## Faster

- `tlh sessions`, `/annotate-git-diff`, `/what-consumed-my-session-limit-and-tokens`, and Gnosis installs are quicker.

## Fixes

- `/annotate-last-message` no longer cuts off long messages.
- Fewer false "finished" notifications and stuck background subagents.
