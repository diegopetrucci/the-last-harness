## Pi 1.1 under the hood

- TLH now runs on Pi 1.1.0. Sessions open in fullscreen mode by default; to keep normal terminal scrollback, set **TUI mode** to "regular" in `/settings`.
- In fullscreen mode, Home and End now move the editor cursor. Use Ctrl+Home and Ctrl+End to jump to the top or bottom of the transcript.
- If you use Azure OpenAI, rename the provider `azure-openai-responses` to `azure` in your auth, models, and settings files.

## Better terminal integration

- TLH now reports whether it's working, waiting on you, done, idle, or errored to terminals that support program status, so their tab and pane indicators stay accurate. Set `TLH_PROGRAM_STATUS=0` to turn it off.
- Session names now show up in your terminal title and in Herdr.

## Smarter defaults

- The context cap is raised from 200k to 300k tokens, and the "DUMB ZONE" footer warning is gone.
- The `developer` subagent now uses Claude Sonnet 5.5 on Anthropic. The lighter helper subagents use Claude Haiku 5.5.
- Fresh installs use Pi's terminal-adaptive `system` theme.
- Web search is leaner: it now offers just its Exa-backed search and fetch tools.

## Fixes

- `--model` and `--thinking` on the command line now take precedence over saved agent defaults.
- Subagent progress is easier to read: the detail lines are aligned, there's one hint per job, and thinking phrases no longer flicker.
- The usage footer stays up to date after model switches and turns.
- `/annotate-git-diff` loads reliably and uses the review colour palette throughout.
- `/toggle-context-cap` no longer corrupts a malformed settings file.
- Pinned extensions no longer drift to newer versions when your profile path goes through a symlink.

## Removed

- The custom review command is gone; the architect still reviews work automatically.
- The Voice and Transcribe extensions are no longer bundled. If you want them, reinstall them yourself.
