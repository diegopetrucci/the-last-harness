## Before you update

- TLH no longer sets `compaction.reserveTokens`; Pi's default reserve applies, and the old TLH-written value is removed once. Set it yourself if you want a custom reserve.
- MCP Apps UI is now off by default; set `MCP_UI_VIEWER=auto` to turn it back on.
- Inside tmux, status and notification updates now need `set -g allow-passthrough all`.

## Updated runtime

- TLH now runs on Pi 1.6.0.
- OpenAI Codex defaults move to GPT-6.2 Sol and GPT-6.2 Astra, and Fast mode now covers them.

## New

- `/skill:ghostty` drives Ghostty.app on macOS.
- The architect now gives an unnamed session a short name once it has planned the work.

## Fixes

- A model you pick with Ctrl+P now stays selected for later prompts.
- Claude Pro/Max sign-in keeps billing correctly on Pi 1.6.0.
- The Xcode MCP bridge now connects only when you first use it.
- Web content fetches with a large limit are trimmed instead of failing.
- Ticket stores no longer leak between sessions.
