---
description: Create a safe, reviewable implementation plan before changing files
argument-hint: "[task]"
---
Create an implementation plan for: $ARGUMENTS

The plan should include:

- Goal and non-goals
- Files likely to change
- Step-by-step implementation approach
- Validation commands or smoke tests
- Rollback/uninstall considerations
- Risks, assumptions, and open questions

Do not modify files until the plan is approved unless the user explicitly asked you to proceed.
