relative to `nicobailon/pi-subagents` (upstream). Governing rules live in
[`AGENTS.md`](../AGENTS.md) under **Fork Sync Policy** — read that first.
`docs/UPSTREAM-SYNC.md` is a historical document kept for reference only.
This table is the record of deliberate fork-only behavior; update it when
adding or removing fork-only behavior, and consult it when porting an
upstream fix to confirm none of these deltas are silently overwritten.
